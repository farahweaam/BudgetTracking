
# Penny - Budget Tracking Website

A web-based budget tracking platform that helps users
manage income, expenses, budgets, and savings goals.

## Technologies

- Angular
- TypeScript
- Firebase Authentication
- HTML
- CSS

## Project Structure

- `frontend/` - Angular application
- `notes.txt` - Project notes

## Running the Project

1. Clone the repository.
2. Open the frontend directory.
3. Install dependencies:

   npm install

4. Start the Angular development server:

   ng serve

5. Open http://localhost:4200
